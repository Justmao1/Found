# 四柜失物招领控制电路 V1

设计日期：2026-10-20。对象：Raspberry Pi 4B、4个 XG4031-A（5V/2A）电磁锁、4路华控5V光耦继电器。设计文档，尚未完成实物验证。

## 已确认的功能边界

- 电磁锁通电弹开、手动合门后机械上锁；电路不能自动把门关上，也不需要通电保持锁住。单次通电必须小于等于3秒。
- 继电器手册指定5V型号按5V输入触发。四路均设为LOW触发，使用NPN开集电极驱动，IN不直接连Pi GPIO。
- 每路加入不可重触发单稳态，防止正常器件条件下GPIO持续高导致线圈持续供电。目标脉冲约0.5秒，实测验收0.4–1.0秒；这不是安全认证或继电器粘连保护。
- 蓝白线仅被原锁说明书标为“锁开关信号反馈线”，未说明内部电路和触点状态。必须确认是与红黑供电绝缘的无源触点后才按本图接入，否则留空，使用独立无源门磁。门磁只能确认门位置，不能证明锁舌已扣合。

## 1. 电源与主回路

P1：Pi独立USB-C电源，5.1V/3A。P2：有过流保护、封闭式低压输出的5V/10A直流电源，给锁和继电器供电。两路正极不相连；负极在GND_STAR单点共地。本方案是共地驱动，不主张完整的电气隔离。

P2+ → F0（10A DC）→ S0（检修断电开关，额定至少12VDC/15A）→ +5_LOCK。

每路i=1..4：+5_LOCK → Fi（3A DC）→ Ki.COM → Ki.NO → Li红线；Li黑线独立回到GND_STAR。Ki.NC不接。Fi保护线路短路，不会在正常2A的持续通电故障下可靠熔断，不能代替脉冲限时。

每把锁就近并联Di=1N5408：阴极K/色环接红线，阳极A接黑线。若锁已有内置抑制器件，先核对厂家要求，避免重复配置改变释放时间。

+5_LOCK → F5（1A DC）→ +5_RELAY → 所有继电器DC+；所有DC-独立回到GND_STAR。若采用四块单路模块，四组DC+/DC-并联供电；若采用一块四路模块，按其公共电源端接。模块输出COM仍需各自接对应保险丝后的电源，DC+不等于输出COM。

C0=1000µF/10V、C01=100nF并联在+5_LOCK与GND_STAR之间；继电器板附近加C02=100µF/10V和C03=100nF。电解电容正极接+5V。电容抑制瞬态，不承担四把锁的工作能量。

四锁同时通电额定8A，加继电器及输入约0.2A（手册典型值），10A电源约有1.8A余量。日常软件串行开锁，电源仍按四路可能同时动作选型。总线建议短距离AWG16，锁支路建议AWG20且单程不超过约1米；原厂细尾线不要继续用细杜邦线延长。配电端子额定至少15A、支路至少5A。实际线径、保险丝曲线和端子需与现场长度/温升配合验证；不要让锁电流经过面包板或Pi排针。

## 2. Pi GPIO与硬件限时

所有编号明确区分BCM与物理针号。

|柜号|命令GPIO / 物理针|单稳态通道|驱动/继电器|反馈GPIO / 物理针|
|---|---|---|---|---|
|1|GPIO17 / 11|U1A|Q1 / K1.IN|GPIO5 / 29|
|2|GPIO27 / 13|U1B|Q2 / K2.IN|GPIO6 / 31|
|3|GPIO22 / 15|U2A|Q3 / K3.IN|GPIO13 / 33|
|4|GPIO23 / 16|U2B|Q4 / K4.IN|GPIO19 / 35|

GPIO25 / 物理22针：ARM，连接U1/U2的两个低有效复位输入R（第3、11脚），用R_ARM=10kΩ下拉至GND。ARM=0禁止并复位四路；ARM=1允许。Pi物理1针3.3V给两片计时芯片与反馈上拉供电。Pi物理6针GND连GND_STAR。

U1、U2必须选TI CD74HC221E（PDIP16，HC型），不是3.3V下不适用的HCT型。每片16脚接3.3V，8脚接GND，16/8脚附近放100nF去耦，控制板另加4.7µF。

|功能|每片A半部|每片B半部|连接|
|---|---|---|---|
|A输入|1|9|直接GND|
|B输入|2|10|相应命令GPIO；各10kΩ下拉|
|低有效复位R|3|11|ARM（GPIO25）|
|Q输出|13|5|相应NPN基极电阻|
|反相/Q输出|4|12|不接|
|Cx|14|6|只接定时电容一端，不接GND|
|RxCx|15|7|接定时电容另一端，并经330kΩ接3.3V|

每通道R_T=330kΩ/1%，C_T=2.2µF/5%或10%低漏电薄膜电容。数据手册t≈0.7RC的条件为VCC=4.5V；3.3V下只是约0.5–0.6秒的起始设计值，必须实测，不作为保证值。电容跨接Cx与RxCx，不是接地。长脉冲精度受漏电、温度、供电及器件影响；验收0.4–1.0秒且能可靠弹开，任何情况单次不得超过3秒。若机械上不能在此时间内开锁，应查压降与安装阻力，不能直接延长到3秒以上。

每路Q输出 → R_Bi=1kΩ → Qi基极B；B至发射极E再接R_BEi=10kΩ；E至GND；C至对应Ki.IN。Qi指定onsemi P2N2222AG：数据手册TO-92脚号1=C、2=B、3=E，实物朝向按厂家封装图，不凭其他2222型号判断。三极管仅承受约9mA的继电器输入电流，不承受锁的2A。

四个继电器跳帽均短接LOW与跳帽中间COM；这个COM不是螺丝端子上的输出COM。

## 3. 反馈电路（四路相同）

每路定义S_i为已经确认的无源触点。优先使用经验证的原锁蓝白反馈触点；不能确认时选择独立无源门磁，并把系统状态标为“门已关闭”，不标成“已锁定”。

3.3V → R_PUi=10kΩ → FB_RAW_i；FB_RAW_i → S_i → GND；FB_RAW_i → R_Si=1kΩ → 对应反馈GPIO；GPIO端 → C_Fi=100nF → GND。上拉只使用3.3V。S_i闭合时读0，断开时读1；锁定/打开对应哪个电平必须现场标定。

确认反馈无源性的方式：先索取厂家触点规格；断电测量蓝白线在锁定/解锁时通断变化，并检查其与红黑线隔离；上电时先不接Pi，用仪表确认反馈线不带主动输出电压。任一项不明确则不接Pi。双绞反馈线与锁电流线分开布线，软件去抖50ms。长距离或强干扰现场另加合适的输入保护/隔离后重新验证。

## 5. 控制流程与验收

启动顺序：ARM先保持0 → 四个命令GPIO输出0 → 读取/标定反馈 → ARM置1 → 等待至少1ms再允许触发。禁止命令脚为高时释放复位，否则可能产生脉冲。程序退出时先ARM置0，再释放其他GPIO。

开第i柜：先验证用户和一次性领取凭证 → 只对相应命令GPIO产生一次20ms高脉冲 → GPIO回0 → 硬件输出约0.5秒 → 验证开锁/开门反馈 → 等待合门并验证稳定反馈 → 写入用户、物品、柜号、时间和最终状态。

普通情况下一个时刻只允许一个开锁事务。任何相同请求重试不能重复触发；不要把认证失败、请求重发或服务重启解释为开锁命令。脉冲未引起预期反馈应报故障，不自动连发。单稳态只能限制每次脉冲，不能阻止软件不断产生新脉冲；原锁未给占空比规格，调试暂留至少30秒冷却间隔，正式使用须由厂家确认允许频次并做温升验证。

存放：空柜预约→授权开柜→放入→合门确认→记录待领取。领取：校验凭证→开指定柜→取走→合门确认→完成领取。门/锁反馈不能确认物品是否实际存在；若要自动判定有物/无物，需另加重量或物体传感器，不在本次电路里假装已具备。

验收顺序：
1. 完全断电，核对二极管方向、芯片朝向、GPIO物理编号、正负极及COM/NO；确认无短路。
2. 暂不接锁，但接好NPN及继电器模块，测量带实际输入负载的计时Q高电平、IN低电平与触点输出，确认可靠吸合/释放。有效命令上升沿以及该命令保持高5秒时，均应只有一个0.4–1.0秒脉冲；上电、重启、复位以及所有B=0时只释放ARM，均应无开锁脉冲。活动脉冲中拉低ARM应使输出提前结束。不能用空载Q波形替代带负载验证。
3. 单锁接入，验证弹开和手动合门，测锁端电压、反馈极性、触点抑制后的释放时间。
4. 再接四锁，验证逐路命令互不串扰。受控测试四路同时动作时的电源压降与Pi稳定性；断言成功须以实测为准。
5. 检查通信中断、服务退出、掉电和重复请求。单稳态不覆盖继电器触点焊死、驱动短路或电源异常等故障；出现持续通电时用S0切断锁电源。原锁机械应急拉杆需保留可维护通道。
